## Plus One

**Algorithm:**

1. Iterate from the last digit to the first
2. If the current digit is less than 9, increment it and return immediately — no carry needed
3. If the current digit is 9, set it to 0 and continue (carry propagates left)
4. If the loop finishes without returning, every digit was 9 — prepend a 1

**Time Complexity:** O(n) in the worst case (all nines)

**Space Complexity:** O(n) only in the all-nines case (new array needed); O(1) otherwise

**Key Insights:**

- A carry only propagates when the digit is exactly 9
- Most numbers end before the loop finishes — early return keeps it fast in practice
- The only case requiring a larger array is 9, 99, 999, … — a single prepend handles all of them

```python
def plus_one(digits):
    for i in range(len(digits) - 1, -1, -1):
        if digits[i] < 9:
            digits[i] += 1
            return digits
        digits[i] = 0
    return [1] + digits
```
