## Fibonacci Number

**Algorithm:**

1. Use iterative approach with two variables
2. Start with base cases F(0) = 0, F(1) = 1
3. Iterate from 2 to n, computing each value as sum of previous two

**Time Complexity:** O(n) - single pass

**Space Complexity:** O(1) - only two variables

**Key Insights:**

- Naive recursion is O(2^n) due to repeated subproblems
- Memoization or iteration reduces to O(n)
- Space-optimized iterative approach only needs two variables
- This is the foundation for understanding dynamic programming

```python
def fib(n):
    if n <= 1:
        return n
    
    prev2, prev1 = 0, 1
    for i in range(2, n + 1):
        current = prev1 + prev2
        prev2, prev1 = prev1, current
    
    return prev1
```
