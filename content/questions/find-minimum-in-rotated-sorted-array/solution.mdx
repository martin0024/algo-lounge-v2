## Find Minimum in Rotated Sorted Array

**Key Insight:** Compare `nums[mid]` to `nums[right]`. If `nums[mid] > nums[right]`, the minimum must be in the right half. Otherwise it is in the left half (including `mid`).

**Algorithm:**

1. Set `left = 0`, `right = n - 1`.
2. While `left < right`, compute `mid`.
3. If `nums[mid] > nums[right]`, set `left = mid + 1`.
4. Otherwise set `right = mid`.
5. Return `nums[left]`.

**Time Complexity:** O(log n)

**Space Complexity:** O(1)

```python
def find_min(nums):
    left, right = 0, len(nums) - 1

    while left < right:
        mid = (left + right) // 2

        if nums[mid] > nums[right]:
            left = mid + 1
        else:
            right = mid

    return nums[left]
```
