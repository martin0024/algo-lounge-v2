## Diameter of Binary Tree

**Algorithm:**

1. Use DFS to calculate depth of each subtree
2. For each node, diameter through it = left\_depth + right\_depth
3. Track maximum diameter seen across all nodes
4. Return depth + 1 for parent nodes

**Time Complexity:** O(n) - visit each node once

**Space Complexity:** O(h) - recursion stack depth

**Key Insights:**

- Diameter may or may not pass through root
- Combine depth calculation with diameter tracking
- Path length is number of edges, not nodes

```python
def diameter_of_binary_tree(root):
    max_diameter = 0
    
    def depth(node):
        nonlocal max_diameter
        
        if not node:
            return 0
        
        # Get depth of left and right subtrees
        left_depth = depth(node.left)
        right_depth = depth(node.right)
        
        # Update maximum diameter (path through current node)
        current_diameter = left_depth + right_depth
        max_diameter = max(max_diameter, current_diameter)
        
        # Return depth of current subtree
        return max(left_depth, right_depth) + 1
    
    depth(root)
    return max_diameter
```
