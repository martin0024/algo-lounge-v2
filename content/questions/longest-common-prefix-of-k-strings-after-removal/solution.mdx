## Store Shared Prefixes in a Trie

A trie stores one character per edge, so every trie node represents a prefix. While inserting the words, count how many words pass through each node. A node is usable when its count is at least k, and its depth is the prefix length.

1. Count how many usable trie nodes exist at every depth.
2. Use a segment tree to quickly ask for the greatest depth whose usable-node count is not zero.
3. When removing a word, inspect only the nodes on that word's trie path. Nodes with a count above k stay usable, while nodes with a count exactly equal to k become unusable.
4. Temporarily update those depths, read the segment tree's maximum, and then restore them before processing the next word.

This avoids rebuilding the trie for every removal. The segment tree is simply a structure that stores the maximum of a range; its root always holds the largest currently valid prefix length.

**Time:** O(L log L), where L is the total length of all words. **Space:** O(L).

```python
def longest_common_prefix(words, k):
    # After any removal, too few words would remain.
    if len(words) - 1 < k:
        return [0] * len(words)

    # Step 1: Build a trie. count[node] is the number of words that contain
    # the prefix represented by that node.
    children = [{}]
    count = [0]
    depth = [0]
    for word in words:
        node = 0
        for character in word:
            next_node = children[node].get(character)
            if next_node is None:
                next_node = len(children)
                children[node][character] = next_node
                children.append({})
                count.append(0)
                depth.append(depth[node] + 1)
            node = next_node
            count[node] += 1

    # Step 2: At each prefix length, count trie nodes shared by at least k
    # words. Any such node is a possible common prefix.
    max_depth = max(map(len, words))
    valid_at_depth = [0] * (max_depth + 1)
    for node in range(1, len(children)):
        if count[node] >= k:
            valid_at_depth[depth[node]] += 1

    # Step 3: Build a segment tree whose root stores the largest depth that
    # still has at least one valid prefix.
    size = 1
    while size <= max_depth:
        size *= 2
    tree = [-1] * (2 * size)
    for current_depth in range(1, max_depth + 1):
        if valid_at_depth[current_depth]:
            tree[size + current_depth] = current_depth
    for node in range(size - 1, 0, -1):
        tree[node] = max(tree[2 * node], tree[2 * node + 1])

    def update(current_depth):
        node = size + current_depth
        tree[node] = current_depth if valid_at_depth[current_depth] else -1
        node //= 2
        while node:
            tree[node] = max(tree[2 * node], tree[2 * node + 1])
            node //= 2

    # Step 4: Remove one word temporarily. A prefix can stop being valid only
    # when it is on this word's path and its original count was exactly k.
    answer = []
    for word in words:
        node = 0
        fragile_depths = []
        for character in word:
            node = children[node][character]
            if count[node] == k:
                fragile_depths.append(depth[node])

        for current_depth in fragile_depths:
            valid_at_depth[current_depth] -= 1
            update(current_depth)
        answer.append(max(0, tree[1]))

        # Restore the temporarily removed word before trying the next index.
        for current_depth in fragile_depths:
            valid_at_depth[current_depth] += 1
            update(current_depth)
    return answer
```
