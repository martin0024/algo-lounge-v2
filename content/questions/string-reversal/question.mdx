Given a string, return it with all characters in reverse order.

## Examples

**Example 1**

```
Input:  "hello"
Output: "olleh"
```

**Example 2**

```
Input:  "abc"
Output: "cba"
```

**Example 3**

```
Input:  ""
Output: ""
```

## Constraints

- String can be empty
- Preserve all characters including spaces
