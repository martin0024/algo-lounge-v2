## Interleaving String

**Algorithm (2D Dynamic Programming):**

1. If `len(s1) + len(s2) != len(s3)`, return `False` immediately
2. Build a DP table where `dp[i][j]` means the first `i` characters of `s1` and first `j` characters of `s2` can form the first `i+j` characters of `s3`
3. Base case: `dp[0][0] = True`
4. Fill first row (using only s2) and first column (using only s1)
5. Transition: `dp[i][j]` is true if we can come from above (`dp[i-1][j]` and `s1[i-1] == s3[i+j-1]`) or from the left (`dp[i][j-1]` and `s2[j-1] == s3[i+j-1]`)

**Time Complexity:** O(m × n) where m and n are the lengths of s1 and s2

**Space Complexity:** O(m × n) for the DP table

**Key Insights:**

- Each cell represents a choice: the next character in s3 comes from s1 or s2
- The length check eliminates trivially invalid cases before building the table
- Characters from s1 and s2 must appear in their original relative order, which the DP structure enforces naturally

```python
def is_interleave(s1, s2, s3):
    m, n = len(s1), len(s2)
    if m + n != len(s3):
        return False
    dp = [[False] * (n + 1) for _ in range(m + 1)]
    dp[0][0] = True
    for i in range(1, m + 1):
        dp[i][0] = dp[i - 1][0] and s1[i - 1] == s3[i - 1]
    for j in range(1, n + 1):
        dp[0][j] = dp[0][j - 1] and s2[j - 1] == s3[j - 1]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            dp[i][j] = (dp[i - 1][j] and s1[i - 1] == s3[i + j - 1]) or \
                       (dp[i][j - 1] and s2[j - 1] == s3[i + j - 1])
    return dp[m][n]
```
