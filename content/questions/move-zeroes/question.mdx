Given an integer array `nums`, move all `0`'s to the end of it while maintaining the relative order of the non-zero elements.

**Note:** You must do this in-place without making a copy of the array.

## Examples

**Example 1**

```
Input:  nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
```

**Example 2**

```
Input:  nums = [0]
Output: [0]
```

**Example 3**

```
Input:  nums = [1,2,3]
Output: [1,2,3]
```

No zeroes to move.

## Constraints

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

> **How the tests work:** the answer is checked by reading your modified input, not your return value.
