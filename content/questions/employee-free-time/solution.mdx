## Employee Free Time

**Algorithm:**

1. Flatten all intervals from every employee into one list
2. Sort by start time
3. Merge overlapping intervals
4. Find gaps between merged intervals - these are free times

**Time Complexity:** O(n log n) where n is the total number of intervals

**Space Complexity:** O(n)

**Key Insights:**

- Individual employee schedules don't matter - flatten everything
- After merging all work intervals, any gap is a common free time
- This reduces to "merge intervals" followed by "find gaps"

```python
def employee_free_time(schedule):
    # Flatten all intervals
    intervals = []
    for emp in schedule:
        for interval in emp:
            intervals.append(interval)
    
    # Sort by start time
    intervals.sort(key=lambda x: x[0])
    
    # Merge overlapping intervals
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1] = [merged[-1][0], max(merged[-1][1], end)]
        else:
            merged.append([start, end])
    
    # Find gaps between merged intervals
    result = []
    for i in range(1, len(merged)):
        result.append([merged[i - 1][1], merged[i][0]])
    
    return result
```
