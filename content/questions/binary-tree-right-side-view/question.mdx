Given the `root` of a binary tree, return the values of the nodes you can see ordered from top to bottom when looking at the tree from the right side.

## Examples

**Example 1**

```
Input:  root = [1,2,3,null,5,null,4]
Output: [1,3,4]
```

The right side view shows nodes 1 (level 0), 3 (level 1), and 4 (level 2).

**Example 2**

```
Input:  root = [1,null,3]
Output: [1,3]
```

**Example 3**

```
Input:  root = []
Output: []
```

## Constraints

- The number of nodes in the tree is in the range `[0, 100]`
- `-100 <= Node.val <= 100`

> **How the tests work:** trees are written as level-order arrays — `[1,null,2]` is a root `1` with a right child `2`. Your function receives real `TreeNode` objects.
