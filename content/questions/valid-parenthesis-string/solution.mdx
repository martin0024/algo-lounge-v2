## Valid Parenthesis String

**Algorithm (Greedy Approach):**

1. Track minimum and maximum possible open parentheses count

2. For each character:

   - If '(': increment both min and max
   - If ')': decrement both min and max
   - If '\*': increment max (treat as '('), decrement min (treat as ')')

3. After each step:

   - If max \< 0: too many ')', return 0
   - If min \< 0: reset to 0 (can use '\*' as empty)

4. Return 1 if min == 0 (all opens matched)

**Time Complexity:** O(n) - single pass through string

**Space Complexity:** O(1) - only two variables

**Key Insights:**

- Track range of possible open parentheses counts
- max represents best case (all '\*' as '(')
- min represents worst case (all '\*' as ')')
- If max \< 0, impossible to balance
- Final min must be 0 for valid string

```python
def check_valid_string(s):
    # Track minimum and maximum possible open parentheses
    min_open = 0  # Minimum possible open parens
    max_open = 0  # Maximum possible open parens
    
    for char in s:
        if char == '(':
            min_open += 1
            max_open += 1
        elif char == ')':
            min_open -= 1
            max_open -= 1
        else:  # char == '*'
            min_open -= 1  # Treat * as )
            max_open += 1  # Treat * as (
        
        # If max becomes negative, too many )
        if max_open < 0:
            return False
        
        # If min becomes negative, reset to 0
        # (we can use * as empty string)
        if min_open < 0:
            min_open = 0
    
    # Valid if we can balance all opens
    return min_open == 0
```
